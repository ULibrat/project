# 🧑‍💻 Uluk Tagaev — Junior Frontend Developer Portfolio

Адаптивный одностраничный сайт-портфолио, разработанный на чистом HTML и CSS. Проект имеет минималистичный дизайн в теплой бежево-черной цветовой гамме, чистую структуру кода и полностью адаптирован под мобильные устройства.

## 🛠 Технологии
Проект написан **без использования сторонних библиотек** и фреймворков:
*   **HTML5** (семантическая и валидная разметка)
*   **CSS3** (Flexbox, CSS Grid, CSS Variables)
*   **Google Fonts** (шрифт Manrope)
*   **Адаптивная верстка** (Media Queries, Mobile-friendly)

## ✨ Особенности проекта
*   **Чистый код:** Логичная структура и понятные классы без перегруза.
*   **CSS-переменные (`:root`):** Все цвета и отступы вынесены в переменные для легкой поддержки и изменения темы.
*   **Адаптивность:** Сайт корректно отображается на смартфонах, планшетах и больших мониторах (перестройка сеток с 3 колонок на 1).
*   **Кастомные иконки:** Для иконок используются стилизованные CSS-блоки (без подключения внешних SVG-спрайтов).
*   **Интерактивность:** Плавные эффекты при наведении (`hover`), фокус на полях ввода формы.
