# 🧑‍💻 Uluk Tagaev — Junior Frontend Developer Portfolio

Адаптивный одностраничный сайт-портфолио, разработанный на чистом HTML, CSS и JavaScript. Проект имеет минималистичный дизайн в теплой бежево-черной цветовой гамме, чистую структуру кода и полностью адаптирован под мобильные устройства. 

Помимо качественной верстки, сайт оснащен интерактивным функционалом: переключением тем, мобильным меню, валидацией формы и анимациями при скролле.

## 🛠 Технологии
Проект написан **без использования сторонних библиотек** и фреймворков:
*   **HTML5** (семантическая и валидная разметка)
*   **CSS3** (Flexbox, CSS Grid, CSS Variables)
*   **Vanilla JavaScript** (ES6+)
*   **Google Fonts** (шрифт Manrope)
*   **Адаптивная верстка** (Media Queries, Mobile-friendly)

## ✨ Особенности и функционал
*   **Переключение тем:** Светлая и темная тема с сохранением выбора пользователя в `localStorage`.
*   **Мобильное меню:** Адаптивный бургер-меню для навигации на смартфонах.
*   **Валидация формы:** Проверка полей (имя, email, сообщение) на пустоту и корректность ввода с выводом кастомных сообщений об ошибках.
*   **Анимация при скролле:** Плавное появление секций при прокрутке страницы с использованием `IntersectionObserver`.
*   **Чистый код:** Логичная структура и понятные классы. Все цвета и отступы вынесены в CSS-переменные (`:root`) для легкой поддержки.
*   **Кастомные иконки:** Стилизованные CSS-блоки вместо тяжелых SVG-спрайтов.
